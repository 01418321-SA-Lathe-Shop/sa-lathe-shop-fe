คู่มือทดสอบระบบตาม Use Case (UC1–UC12)

ระบบสั่งผลิตงานกลึงตามสั่ง (Machine Shop Custom Manufacturing) — ทดสอบตามลำดับ UC1 → UC12 เพราะข้อมูลของแต่ละขั้นต่อยอดจากขั้นก่อนหน้า ติ๊กช่องเมื่อผ่านแต่ละขั้น (ระบบจำไว้ในเบราว์เซอร์นี้เท่านั้น)

ฉบับวันที่ 4 พ.ย. 2569เวลาแสดงเป็น Asia/Bangkok · เงินเป็นบาท ไม่รวม VAT
เตรียมระบบ

เตรียมระบบก่อนทดสอบ

  1. รัน Backend (Go) ที่ http://localhost:8080 บนฐานข้อมูลทดสอบที่ seed บัญชีตัวอย่างแล้ว และตั้ง LOCAL_TEST_ACCOUNT_ENABLE=true (ผู้ดูแลระบบ backend เป็นผู้เตรียม)
  2. ฝั่ง Frontend ใส่ NEXT_PUBLIC_API_BASE_URL=http://localhost:8080 และ NEXT_PUBLIC_LOCAL_TEST_LOGIN_ENABLED=true ใน .env.development.local แล้วรัน npm run dev
  3. เปิด http://localhost:3000/login จะเห็นปุ่มบัญชีทดสอบ 6 บัญชี กดเพื่อเข้าสู่ระบบได้โดยไม่ต้องใส่รหัสผ่าน
  4. ระหว่างทดสอบ ใช้เมนู สลับบัญชีทดสอบ ในแถบด้านข้างเพื่อเปลี่ยนบทบาทโดยไม่ต้องออกจากระบบ
  5. ถ้าทดสอบบนเซิร์ฟเวอร์ที่ deploy แล้ว (Vercel + Railway) จะไม่มีปุ่มเข้าแบบไม่ใช้รหัสผ่าน ให้เข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่านที่ผู้ดูแลแจกให้
