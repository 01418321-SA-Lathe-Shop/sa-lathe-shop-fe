## What changed from the source description

- UC10: the description asks for rename and factor edit. The backend uses deactivate-and-add instead, to keep history immutable.
- UC11: the description allows adopting an existing person and checks duplicate contacts. Neither is in the contract.
- UC12: the description introduces a super-admin level that the owner has not confirmed.
