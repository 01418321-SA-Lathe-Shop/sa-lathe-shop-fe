# Staff/Admin Overview surface

Mode: Operate. Audience: active Staff viewing the shared shop queue, and Admin
monitoring shop work with existing worker-management navigation. No assignment,
new production command, customer data exposure or navigation-shell redesign.

## Direction contract

THESIS: Replace the menu-directory overview with a quick operational read:
current creation-cohort states, real first completions, then named job rows.
OWN-WORLD: Existing orange/charcoal and warm-white themes, existing font and
scale preferences; restrained 16px panels, 8/16/24px rhythm, readable metadata.
STORY: Understand queue size, inspect actual completion history, open a real job.
FIRST VIEWPORT: Retained navbar/drawer; compact heading and range selector;
four equal metrics at left, priority queue at right; heatmap before the job
table and shortcuts below priority. Main content fills available stage width.
FORM: Owner-pinned dashboard reference; no concept roll or replacement palette.
Signature interaction: selecting a metric/day focuses the matching named list;
no dashboard mutation shortcuts or speculative ETA/readiness. No entrance motion.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Implemented surface includes summary/list/priority/navigation, report errors and
the interactive twelve-month first-completion calendar. No raster assets needed.
Calendar days support arrow/Home/End navigation, named day previews, a native
date alternative and the same filtered job list. Dense cells have a separate
44px date control; page scrolling never expands to calendar width.
